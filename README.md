## Introduction to Lab Assignment 2
This assignment introduces students to using machine learning applications in python with using real applicable data from GNSS and accelerometer and movement data. Students learned how to perform nonlinear least squares, gradient descent, and classification using support vector machine. This assignment as been split into two parts, which each has four and three subsections, respectively. The first part of the project focuses primarily on using nonlinear least squares and gradient descent to estimate position of a GNSS receiver. The second part of the project involves motion classification with inertial sensor data on a training/testing dataset followed by testing on two other individual datasets. We learned how to apply python function including pandas, numpy, matplotlib, and various machine learning imports including sklearn. Throughout this assignment, we were required to apply our knowledge about statistics and various machine learning models to real observations as well as explain our findings and evaluate our models. 
## Part 1: Nonlinear Least Squares Estimation
Part 1 included applying knowledge of nonlinear least squares estimation in order to estimate the position of a GNSS receiver using observations of straight-line distance between antennas in addition to the satellites positions. Section 1.1 involves loading the data from the dataset into the appropriate dataframes, ensuring that the rows in the datasets correspond to each other to perform the analysis successfully, for that we merge satellite_positions.csv and satellite_ID to ensure row to element correspondece between pseudorange measurements and satellite coordenates, and added zero-mean Gaussian noise to generate the final pranges vector. 
Section 1.2 is given, it contains the formulas needed in order to perform nonlinear least squares estimation, including the design matrix. In order to complete section 1.3, first we evaluate the design matrix and the misclosure vector for a single iteration, followed by solving a nonlinear least squares formula for another single iteration in order to determine receiver position estimation. After this, we performed the non-linear least squares estimation on all of the data until convergence was reached. The correction, misclosure, estimate parameters vectors, estimated parameters, observation residuals, variance factor, and covariance of the estimated parameters was stored in variables. After being provided with the true position of the receiver, we computed the 3D position errors at each iteration, resulting in a final 3D error. Finally, using this information, we were able to print and label the converged estimate receiver position and clock bias, correction applied at the final iteration, posterior variance factor, and more. After provided with the position of the receiver, we were then able to compute the errors for the estimated position and the receiver position in each iteration. We then produced a single figure using matplotlib with three subplots that consists of the residuals, misclosures and position error as a function of iteration number. For section 1.4, we performed the GPS position estimation using nonlinear gradient descent, first we defined the function to evaluate the cost and gradient of the nonlinear observation model. Following this, we performed nonlinear gradient descent in order to estimate the position, which allowed us to compute the error in the estimated receiver position. We plotted the cost at each iteration step along with the line graphs of the gradient components and the position errors at each iteration. We also re-performed gradient descent with the learning rates provided in the assignment, before analyzing our results.
## Part 2: Machine Learning
Part 2 involved classification using support vector machine (SVM) in order to perform motion classification using inertial sensor data on two individual testing datasets and then evaluating the model. The first section of part 2 involved using all features excluding the target vector (which was motion state) in the training and testing of the model before it was tested on the two independent datasets. The second section involved using pre-selected features to test the data, and finally the third section of the data used features that were selected by the group and then tested on the data. Section one required us to load all of the datasets into dataframes and then perform a grid search with cross validation, with the target vector being stored in the y variable and all other features being stored in the X variable. The dataset was then split into training/validation and testing sets, which then required us to use train_test_split from sklearn. A pipeline was initialized using a scaler and a classifier followed by a definition of a grid search configuration for hyper parameter tuning of the support vector classifier. The model was then evaluated by printing a confusion matrix and classification report to visualize the results and allow us to comment on the overall fit of the model to the training model and to the two independent testing sets. Using this step-by-step process, we applied this to the second and third section, however the X variables consisted selected features for the second and third section in order to evaluate the models differently. The second section contained pre-selected features, which consisted of ax_var, ay_var, az_sum, a_sum, and gz_var. The third selection contained features that we selected ourselves, which include gx_var, gy_var, g_sum, az_var, and a_sum. Throughout all of the sections, we analyzed the fit of the model based on the classification report, and whether or not the model was successful on the individual testing datasets. This part of the assignment provided us with further insight into developing machine learning models as well as effective evaluation techniques. Understanding how including certain features from the training dataset also provided allowed us to fully understand how to develop an effective model on other independent testing sets.
